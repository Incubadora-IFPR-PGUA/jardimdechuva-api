# TEMT6000 — Sensor de Luminosidade

## Identificação
- **Grandeza medida:** Luminosidade / intensidade luminosa ambiente
- **Unidade:** valor analógico bruto (0–4095); conversão aproximada para lux
- **Interface:** analógica
- **Foto:** `img/temt6000.jpg`

## Especificações
| Parâmetro | Valor |
|-----------|-------|
| Faixa de medição | Luz visível, resposta similar ao olho humano |
| Precisão | Aproximada (sensor de baixo custo, não calibrado em lux) |
| Tensão de operação | 3,3 V |
| Consumo | Muito baixo (µA em repouso) |
| Interface | Saída analógica (0–VCC) |

## Calibração
Não requer calibração absoluta para o uso atual (leitura relativa de luminosidade). Para conversão em lux, seria necessária calibração contra luxímetro de referência.

## Proteção ambiental
Requer janela óptica transparente no encapsulamento (não pode ser vedado opaco). Em ambiente costeiro, proteger a face traseira e conexões contra maresia com conformal coating, mantendo o elemento fotossensível exposto sob proteção transparente.

## Status no projeto
- **Situação:** em produção
- **Leituras persistidas:** 15.000+
- **Notas:** Primeiro sensor validado no pipeline completo (ESP32 → MQTT → API → MySQL).
